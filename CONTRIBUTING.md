# Contribuir

1. No añadas datos ni URLs de tenants reales.
2. Conserva `observe` como modo seguro y evita escrituras implícitas.
3. Añade una prueba determinista para cada cambio de contrato.
4. Ejecuta `npm run check` antes de proponer el cambio.
5. Distingue siempre simulación, validación nativa y producción.

Los cambios de API SAP deben enlazar documentación oficial y mantener rutas y
campos configurables cuando varíen por edición o tenant.
